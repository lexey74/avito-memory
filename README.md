# Расширение Chrome для поиска на Avito


### Решает вот такую мою боль:
Когда ищешь товар, просматриваешь много карточек, делаешь какие-то выводы, но они не сохраняются. Через некоторое время просто забываешь, какое решение ты принял по той или иной карточке и тратишь время на анализ заново.

Я решил, что было бы удобнее сразу делать заметки к карточкам и ставить свой вердикт ("Хороший товар", "Не подходящий" и "Так себе" = надо подумать). А также писать пояснения, почему такое решени принял
Сообстветственно, в списке товаров принятое решение должно быть доступно без необходимости проваливаться в карточку. Даже если список товаров перестроен (наложены другие фильтры, появились новые товары и т.п.)

В общем-то этот аддон решает эту задачу.
В меню aad-on "Параметры" можно увидеть таблицу со всеми проработанными карточками, отсортировать карточки по цене и принятому решению, перейти в любую из карточек.

### Установка
1. Скачиваем и распаковываем .zip в любой удобной папке на вашем локальном компьютере
2. Открываем вкладку Расширения (в командной строке можно набрать chrome://extensions/)
3. Обязательно(!) включаем "Режим разработчика" он позволит загружать расширения не из Chrome Store
4. Нажимаем кнопку "Загрузить распакованное расширение"
5. В открывшемся диалоге выбираем ПАПКУ с распакованным расширением

### Как работает
1. Заходим на Avito.ru, задаем поиск по товарам
2. Выбираем понравившийся в спике товар, открываем его карточку
3. Сразу после названия увидим форму с тремя эмодзи и текстовым вводом комментариев
4. Пишем комментарий, выбираем один из трех эмодзи. Как только фокус с формы ввода уйдет, данные сохранены
5. Возвращаемся в список, обновляем экран (F5)
6. Ищем обработанную картчоку в списке, в левом нижнем углу фото видим эмодзи
7. При наведении на эмодзи пкурсор меняется на знак вопроса, при клике всплывает ваш комментарий по этому товару
8. Клик в любом месте убирает высплывший комментарий
