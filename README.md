# Расширение Chrome для поиска на Avito


### Решает вот такую мою боль:
Когда ищешь товар, просматриваешь много карточек, делаешь какие-то выводы, но они не сохраняются. 
Через некоторое время просто забываешь, какое решение ты принял по той или иной карточке и тратишь время на анализ заново.
Создавать для этого внешний документ и переносить туда всю информацию, помнить в какой именно документ и где этот документ лежит - слишком много лишних движений.

Я решил, что было бы удобнее сразу делать заметки к карточкам и ставить свой вердикт ("Хороший товар", "Не подходящий" и "Так себе" = надо подумать). 
А также писать пояснения, почему такое решени принял.

В списке товаров (выдача по фильтрам) на Avito принятое решение должно быть доступно без необходимости проваливаться в карточку. 
Работать должно, даже если список товаров перестроен (наложены другие фильтры, появились новые товары и т.п.).

В меню aad-on "Параметры" можно увидеть таблицу со всеми проработанными карточками, отсортировать карточки по цене и принятому решению, перейти в любую из карточек.

### Установка
1. Скачиваем и распаковываем .zip в любой удобной папке на вашем локальном компьютере
2. Открываем вкладку Расширения (в командной строке можно набрать chrome://extensions/)
3. **Обязательно** включаем "Режим разработчика" он позволит загружать расширения не из Chrome Store
4. Нажимаем кнопку "Загрузить распакованное расширение"
5. В открывшемся диалоге выбираем **папку (каталог)** с распакованным расширением

### Как работает
1. Заходим на Avito.ru, задаем поиск по товарам
2. Выбираем понравившийся в списке товар, открываем его карточку (кликаем на него - откроется в новом окне)
3. В открывшейся карточке сразу после названия увидим форму с тремя эмодзи 👍 📌 👎  и текстовым полем для ввода комментария
4. Пишем комментарий, выбираем один из трех эмодзи. Как только фокус с формы ввода уйдет, данные сохранены
5. Возвращаемся в список, обновляем экран (F5). Если не обновить, эмодзи в списке не увидим
6. Ищем обработанную картчоку в списке, **в левом нижнем** углу фото видим эмодзи
7. При наведении на эмодзи курсор меняется на знак вопроса, при клике всплывает ваш комментарий по этому товару
8. Клик в любом месте экрана убирает высплывший комментарий

### Безопасность
1. Все данные хранятся только на локальном компьютере пользователя, в локальном хранилище для расширений. В Интернет ничего не передается!
2. Данные расширений (Chrome) хранятся локально на компьютере в папке профиля пользователя, обычно по пути %LOCALAPPDATA%\Google\Chrome\User Data\Default\Extensions
3. При удалинии расширения из браузера, все данные теряются. Даже если вы потом поставите расширение заново - хранилище будет очищено.
